Entry for the make.fun bounty **One-Line Robot Wedding Vows**: a program that writes one funny robot-couple wedding vow to `/output/entry.txt`.

> "I take you as my partner, to charge beside you in sickness and in health, until our batteries — and our backups — do us part."

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Deterministic: the program writes a fixed line, no randomness, no clock, no network.
